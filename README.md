# Proyecto Computacion Numerica LAB - La ganancia que se evapora

Se necesita analizar la variacion del peso chileno respecto al dolar, para ello se emplearan distintos metodos. Se aplicaran conceptos como cifras significativas, puntos flotantes y definiciones de error para responder diversas preguntas de analisis.

## Estructura de carpetas

- ProblemaDolarSII -> Carpeta principal del proyecto.
  - data -> Almacena el archivo con los datos del dolar y un archivo generado con el analisis.
  - graficos -> Graficos generados del analisis del proyecto.
  - src -> Codigo fuente del proyecto.
    - anualidades.py -> Modulo para manipulacion de datos anuales.
    - cargar_datos.py -> Modulo para cargar archivo.
    - errores.py -> Modulo con operaciones referidas a las definiciones de error.
    - graficos_obligatorios.py -> Archivo necesario para generar todos los graficos obligatorios presentes en el proyecto.
    - preguntas_error.py -> Archivo que responde a las preguntas del punto 6.Preguntas del error a contestar del proyecto.
    - punto_flotante.py -> Archivo que reponde a las preguntas del punto 7.Preguntas del punto flotante a contestar del proyecto.
    - main.py -> Archivo que importa todas las funciones ejecutables de los demas archivos, para poder generar los resultados.
  - INFORME.md
  - README.md
  - Problema_laboratorio.pdf
  - requirements.txt
