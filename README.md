# Proyecto Computacion Numerica LAB - La ganancia que se evapora

Se necesita analizar la variacion del peso chileno respecto al dolar, para ello se
requiere trabajar con 2 cifras significativas (generando un error respecto al valor real).
Los valores deberan ser analizados para encontrar patrones de compra/venta, para ello se necesita calcular: Compra de dolares - Venta de dolares - Ganancia - Rentabilidad - Variacion entre meses
